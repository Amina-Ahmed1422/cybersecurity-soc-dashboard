# cybersecurity-soc-dashboard
Power BI dashboard for analyzing authentication logs and potential brute-force activity
Cybersecurity SOC Monitoring Dashboard
Project Overview
This project uses Power BI to analyze synthetic authentication logs and visualize login activity and potential security threats.
Objectives
• Analyze total login attempts.
• Compare failed and successful logins.
• Identify source IPs with unusually high numbers of failed attempts.
• Visualize login activity and suspicious patterns.
Tools
• Microsoft Power BI
• Microsoft Excel
• DAX
• Cybersecurity Log Analysis
Dataset
The dataset contains synthetic login events created for educational purposes. It does not contain real user or security data.
Security Note
Repeated failed logins may indicate potential brute-force activity, but further investigation is required to confirm an attack.
